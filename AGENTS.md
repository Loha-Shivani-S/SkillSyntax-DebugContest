# SYSTEM FAILURE — Hardware × Software Debugging Challenge

This repository contains the official platform for **SYSTEM FAILURE**, a 90-minute college-level C programming debugging competition for Electronics and Instrumentation Engineering (EIE) students.

## Architecture Guidelines
- **Frontend**: React 19, TypeScript, Tailwind CSS, Monaco Editor, TanStack Router.
- **Backend**: TanStack Start / Node.js server functions.
- **Sandboxed Execution**: Remote compiler execution (Judge0 / GCC sandbox) — never execute submitted C code on the web host.
- **Scoring**: 12 challenges, 100 points total. Strict progression from sensor acquisition up to master plant supervisory controller.
